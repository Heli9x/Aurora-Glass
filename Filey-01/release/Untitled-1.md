<designated_filey_storage>/<media_type>/cache/<uuid>/ this stays in filey's managed space, Filey should not write cache and UUIDs into system/user defined dirs apart from the one assigned to it. in simple words UUIDs and cache stay here (cache storage becomes more discreet) while actual files are stored in their system native/user defined dirs. if a file is not managed by filey i.e its dir is unknow the user can expand it by adding a new category. For example GGUF files can maybe attain a library of their own called 'AI files' with their storage defined by the user (this feature is event driven-not installed on first use).
