# Filey UI screenshots

These captures document the main Filey workflows using the live browser UI. They use the current sample library and are intended as product documentation and advertising reference images.

## Library overview

The Home view presents the personal library with navigation, sorting, grid/list switching, file cards, and top-level maintenance actions.

![Filey Home library overview](screenshots/home-library.png)

## Media libraries

Movies and Photos provide focused views for different media types. Photos uses generated thumbnails where available.

## Upload and file actions

The upload dialog supports a drop zone, custom naming, automatic or explicit categorization, and custom icons. The context menu keeps common file operations close to each card.

![Filey upload dialog](screenshots/upload-dialog.png)

![Filey file context menu](screenshots/context-menu.png)

## Settings and guide

Settings expose the platform name, storage location, browser defaults, and restart note. The Info view provides expandable guidance for getting started and managing a library.

![Filey settings and storage](screenshots/settings-storage.png)

![Filey in-app guide](screenshots/info-guide.png)
